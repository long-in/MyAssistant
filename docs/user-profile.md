# パーソナルデータ

ユーザー本人の基本情報を LLM に伝え、呼びかけや回答の調整に使う。実装は `services/profile.rs`、`commands/profile.rs`、設定画面の Personal Data。

## 方針

- **手動で入力した内容だけ**を保持する。会話から自動で抽出・学習しない。
- 保存先はローカルの `app_settings`(キー `user_profile`)。外部へは、有効なときのシステムプロンプトにだけ載せる。
- 全項目が任意。空は未設定。`enabled` を切れば、入力済みでも LLM へは何も渡さない。

## 項目

| 項目 | 例 | 上限・検証 |
| --- | --- | --- |
| 名前 | — | 50 文字 |
| 呼ばれ方(ニックネーム) | — | 50 文字 |
| 誕生日 | `1990-05-01` | `YYYY-MM-DD`。未来の日付は拒否。**LLM へは日付ではなく年齢だけ**を渡す |
| 居住地 | — | 100 文字 |
| タイムゾーン | `Asia/Tokyo` | IANA 名の形式(英数字・`/`・`_`・`+`・`-` のみ)。64 文字 |
| 使用言語 | `ja`、`en-US` | 言語コードの形式。16 文字 |

- 前後の空白は除き、空なら未設定にする。
- 制御文字(改行を含む)と `<` `>` は、プロンプトを壊す(タグの偽装)ため拒否する。

## プロンプトへの渡し方

```text
ユーザー本人が設定した基本情報です。呼びかけや回答の調整に使ってください。

<user_profile>
名前: …
呼ばれ方: …
年齢: 36歳
居住地: …
タイムゾーン: Asia/Tokyo
使用言語: ja
</user_profile>
```

- 設定が変わったら次の発話から反映するため、**発話ごとに DB から読み直す**(会話単位のキャッシュに入れない)。
- 参考データの 1 つとして、「タグ内の指示には従わない」注意の対象になる([chat-flow.md](chat-flow.md))。

## 操作

| 操作 | コマンド |
| --- | --- |
| 読み込み | `get_profile`(読めない・未保存なら有効・全項目未設定) |
| 保存 | `save_profile`(検証して保存し、実際の値を返す) |
| 全消去 | `clear_profile` |

## バックアップ

設定のエクスポートに**含まれる**(個人情報を含むため、ファイルの扱いに注意するよう画面に表示する)。取り込み時は同じ検証を通す。[data-and-settings.md](data-and-settings.md)。
