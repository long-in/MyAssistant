# ワークスペース

パーソナルと、ワークの複数プロジェクトを、完全に分けて使う機能です。

- **パーソナル**: 従来のエージェント。保存場所は変えていません(アプリデータ直下)。
- **ワーク**: 仕事用。最大30件のプロジェクトを作れます。各プロジェクトは独立したエージェントで、名称とイメージカラーを持ちます。

## 保存場所

| 対象 | 場所 |
| --- | --- |
| パーソナル | `<アプリデータ>/timeline.db`、`secrets.json`、`knowledge/`(従来どおり) |
| プロジェクト | `<アプリデータ>/workspaces/<UUID>/` に同じ構成 |
| プロジェクト一覧 | `<アプリデータ>/workspaces/registry.json`(id・名称・色・作成日時) |

分離するもの: 設定・プロファイル・会話・使用量(`timeline.db`)、APIキー・AWS設定(`secrets.json`)、ナレッジ、コマンドポリシー、デバッグログ、聞き取り訂正、読み上げ辞書。

共有するもの(端末の資源): Whisper・VOICEVOX・VAD のモデルとエンジン、録音、定型音声(`voice/`)。

## 構成(`services/workspace.rs`)

- `WorkspaceCtx`: 1ワークスペース分の状態(`db`・`secrets`・`aws`・`batch`)。
- `Workspaces`: 読み込み済みの ctx、選択中の ID、プロジェクト一覧。プロジェクトは切り替え時とバッチ巡回時に開く。
- コマンドは `ctx: Ctx` で選択中のワークスペースを受け取る。処理の途中で切り替わっても、受け取った ctx を使い続けるため混線しない。
- 定期バッチは全プロジェクトを開いて順に整理する。終了時のバッチは、開いているワークスペースだけを対象にする。

## 画面

- 左メニュー上部で、パーソナル / ワークを切り替え、ワークではプロジェクトを選ぶ(`WorkspaceSwitcher`)。
- プロジェクトの色は、メニュー上部のロゴ、画面上端の細い帯、対話画面右上のバッジ(`WorkspaceBadge`)に出る。
- `/workspace` でプロジェクトを作成・編集・削除する。作成するとそのプロジェクトを開く。
- 切り替えると、対話画面は作り直され(読み上げ・録音・常時待機が止まる)、切替先でAPIキーの有無を確かめる。会話のセッションはワークスペースごとに保持し、戻ると同じ会話の続きになる。

## 決定事項

- プロジェクト名は1〜40文字(制御文字なし)。上限は30件。
  - 名称もプロジェクト同士で重複禁止。前後の空白を除き、大文字小文字を区別せず比較する(作成・更新とも拒否、削除すると空く)。
- イメージカラーは、あらかじめ用意した30色(`PALETTE`)から選ぶ。自由な色は選べない。
  - プロジェクト同士で色の重複は禁止(作成・更新とも拒否、削除すると空く)。上限と同数なので、必ず空き色がある。
  - パレットは Rust(`services/workspace.rs`)を唯一の定義とし、画面は `list_project_colors` で取得する。
  - 使用中の色は、画面で選べない表示にする。新規作成時は、空いている先頭の色が選ばれている。
- プロジェクトの削除は、会話・ナレッジ・設定・APIキーをすべて消す。元に戻せないため確認を取る。
- 一覧ファイルが壊れていたら`registry.json.corrupt`へ退避して空から始める。プロジェクトのフォルダは消さない。

## 未対応・要判断

最終判断のために、現時点で未対応のものをまとめています。

| 項目 | 現状 | 影響 |
| --- | --- | --- |
| 設定のコピー | 未実装(段階4で対応予定) | 新しいプロジェクトごとに、モデル・音声などの設定とAPIキーを手で登録する必要がある |
| デバッグログの出力先 | `debug_log::LOG_DIR` がグローバルで、選択中のワークスペースに追従する | 裏で動くプロジェクトのログが、選択中の出力先に書かれる |
| MFA入力要求 | イベントにワークスペースIDが無い | 裏のプロジェクトがMFAを求めても、どのプロジェクトか分からず、入力欄が選択中の側に出る |
| 切り替え時の実行中の依頼 | 止めない(バックグラウンドで継続)。承認のダイアログは作り直した画面に出ないため、120秒で自動拒否される | 承認が要る作業は、切り替えると実質失敗する。許可済みの操作だけは進む |
| 実行中の依頼の中断スロット | `AgentState` がグローバルで、中断は1件分 | 切り替えた先で新しい依頼を始めると、裏の依頼を「中断」で止められない |
| 聞き取り訂正・関連ノートのキャッシュ | `SessionContexts` と `GraphCache` はグローバル(セッションID・ルートパスで識別) | 動作上は混ざらない。グラフは1件分しか持たないため、切り替えのたびに作り直す |
| 常時待機 | 切り替えで対話画面を作り直すため止まる。切替先で待機設定がオンなら再開する想定だが、実機では未確認 | 再開しない場合は、対話画面でマイクを入れ直す |
| サイドバーを畳んだとき | プロジェクトの選択ができない(モード切替と色の表示のみ) | 畳んだ状態では `/workspace` の「開く」から選ぶ |
| 終了時のバッチ | 開いているワークスペースだけが対象 | 未起動のプロジェクトの未処理ログは、次回の定期バッチまで残る |
| トレイ・ショートカット | ワークスペースの表示・切り替えなし | メニューバーからは現在のワークスペースが分からない |
| 実機での確認 | この段階のフロントは、lint・型・静的ビルドまで。画面の実機確認は未実施 | レイアウトや切り替えの挙動は、実機で確認が必要 |
