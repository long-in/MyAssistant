# 通信のプロキシ

アプリの外向きの通信をプロキシ経由にする機能。プロキシは全体設定で複数登録し、既定を1つ決める。各エージェントは、設定で使うプロキシを選ぶ。実装は `services/proxy.rs` と `commands/proxy.rs`。

- 登録・既定: 全体設定「その他」の Proxy。
- 選択: エージェントの設定「その他」の Proxy。

## 設定項目

| 項目 | 保存先 | 内容 |
| --- | --- | --- |
| `proxy_list` | `work/global_settings.db` | 登録したプロキシのJSON配列。各件は `id`(英数字・`-`・`_`、64文字まで。`none` は不可)・`name`(60文字まで)・`url`・`username` |
| `proxy_default` | 同上 | 既定のプロキシのID。空なら既定なし |
| パスワード | `<アプリデータ>/proxy/secrets.json` | IDごとに `proxy_password:<id>`。権限 0600。`services/secrets.rs` の外へ出さず、画面へは登録の有無(bool)だけ返す |
| `proxy_choice` | エージェントのDB(`app_settings`) | そのエージェントの選択。空は「既定を使う」、`none` は「使わない」、それ以外は登録済みのID |

- URLは `http://ホスト:ポート` または `https://…`。認証情報は含められない。不正な保存は拒否する。
- パスワードは「据え置き(未入力)/更新/削除」を区別する(`save_proxy` の `password`: `None` / 文字列 / 空文字)。ユーザー名が空なら認証なし。
- プロキシを削除すると、パスワードも消える。既定だった場合は既定なしになる。

## どの通信がどのプロキシを使うか

| 通信 | 使うプロキシ |
| --- | --- |
| エージェントに紐づく通信(Anthropic の呼び出し・Google の音声合成/認識・AWS(STS・SSO)) | そのエージェントの選択。「既定を使う」なら既定 |
| エージェントに紐づかない通信(Whisper・VOICEVOX・ローカルLLMのモデルの取得、キーの確認) | 常に既定 |

- 選んだIDが一覧に無いとき(削除された、設定の取り込み先に無い)は、「既定を使う」として扱う。
- 既定が無いとき、「既定を使う」はプロキシなし。
- `localhost` / `127.0.0.1` / `::1` 宛て(VOICEVOX・ローカルLLM のサーバーへの通信)は常にプロキシを通さない。
- プロキシなしのときは従来どおり(reqwest は環境変数 `HTTP(S)_PROXY` 等に従う。AWS SDK はプロキシ無し)。
- コンテナ内の Claude Code とコマンドの通信(Bedrock など)には、このプロキシの設定を渡さない([sandbox.md](sandbox.md))。

## 反映のしかた

- 起動時に `proxy::init` が保存済みの設定を読み、保存のたびに `proxy::reload` がメモリの一覧を入れ替える。エージェントの選択は通信のたびにDBから読む。通信は呼び出しのたびにクライアントを作るので、**保存した次の通信から**反映される(再起動は不要)。
- reqwest の通信は `proxy::client_builder_for(ctx)`(エージェントに紐づく)または `proxy::client_builder()` / `proxy::get()`(紐づかない)を通す。
- AWS SDK は、`proxy::aws_http_client_for(ctx)` が返すHTTPクライアントを設定する(プロキシなしなら SDK の既定のまま)。

## 設定の書き出し・コピー・バックアップ

- 一覧(名前・URL・ユーザー名)と既定(`proxy_list` / `proxy_default`)は全体設定にあり、アプリ全体のバックアップに含まれる。エージェントの選択(`proxy_choice`)は、エージェントの設定の書き出し・取り込みと、エージェント間の設定のコピーの対象。読み込んだ一覧の不正な件(ID・名前・URLが不正、IDが重複)は無視する。
- **パスワードは設定の書き出し・コピーに含めない**(APIキーと同じ)。取り込み先で必要なら入力し直す。アプリ全体のバックアップ(zip)には、APIキーと同様に平文で含める([backup.md](backup.md))。

## 制約

- 対応するスキームは `http` / `https` のプロキシのみ(SOCKS は非対応)。認証は Basic。
- Web 検索・ページ取得は Anthropic のサーバー側ツールで行うため、アプリからの通信は Anthropic への接続のみ(プロキシ対象)。
